# イクマ 数値管理シート

Instagramインサイトの数値を記録するExcelファイル。陸斗さんが日々インサイトのスクショを送ってくるので、その内容をこのファイルに反映していく。

## シート構成
- **日次ログ**:概要タブ+オーディエンスタブの全項目を1行/日で記録
- **ストーリーログ**:ストーリーごとの閲覧数/リプライ数/タップして次へ・戻る/ステッカータップ数など
- **投稿ログ**:通常投稿(フィード投稿)ごとの閲覧数/いいね/コメント/シェア/保存/新規フォロー数(リールはここに含めない)
- **リールログ**:リール個別インサイト(スキップ率・保存率・流入元など)の深掘りデータ。伸びているリール・気になるリールを対象に記録(全リール毎日は非現実的)
- **週次ログ**:週1回、その週の各ログを集計して振り返り(保存率平均・フォロー転換率・一番伸びたピラー等)

## 運用ルール(陸斗さんの指示:2026-09-28)
今後、このファイルへの反映は**投稿・分析担当が担当**する。全体とりまとめ(ピギー)は、陸斗さんから届いたインサイトのスクショの内容をテキストで投稿・分析担当に伝達し、投稿・分析担当がこのExcelファイルを実際に更新してpushする。

コンテンツ種別ごとにスクショが届くタイミングが異なる運用になっている:
- **ストーリー**:投稿から**24時間後**(公開終了後の最終インサイト)にスクショが届く → ストーリーログに反映
- **投稿・リール**:投稿から**5日後**(数値が安定してから)にスクショが届く → 投稿ログ/リールログに反映
- **日次ログ**:毎日届くプロフィール全体のインサイト(概要+オーディエンス)を該当日の行に反映
- **週次ログ**:週の区切り(日曜日想定)で、その週の各ログを集計して1行追加

## 数値の出典
すべて陸斗さんが送ってくれたInstagramインサイトのスクリーンショットから読み取ったもの。スクショに写っていない項目は空欄のままにし、憶測で埋めない。
