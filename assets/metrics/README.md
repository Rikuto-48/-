# イクマ 数値管理シート

Instagramインサイトの数値を記録するExcelファイル。陸斗さんが日々インサイトのスクショを送ってくるので、その内容をこのファイルに反映していく。

## シート構成
- **日次ログ**:概要タブ+オーディエンスタブの全項目を1行/日で記録
- **ストーリーログ**:ストーリーごとの閲覧数/リプライ数/タップして次へ・戻る/ステッカータップ数など
- **投稿ログ**:通常投稿(フィード投稿)ごとの閲覧数/いいね/コメント/シェア/保存/新規フォロー数(リールはここに含めない)
- **リールログ**:リール個別インサイト(スキップ率・保存率・流入元など)の深掘りデータ。伸びているリール・気になるリールを対象に記録(全リール毎日は非現実的)
- **週次ログ**:週1回、その週の各ログを集計して振り返り(保存率平均・フォロー転換率・一番伸びたピラー等)

## 運用ルール(陸斗さんの指示:2026-10-29更新)
このファイルへの反映は**陸斗さんご本人が直接行う**。以前はスクショを投稿・分析担当(運用チーム リール・ストーリーと同一)に伝達して代理入力する運用だったが、スクショを送る手間の方が大きいため廃止。陸斗さんが直接このExcelファイルを更新してpushする(ピギー・投稿・分析担当を経由しない)。

参考として、コンテンツ種別ごとの反映タイミングの目安は変わらず以下の通り:
- **ストーリー**:投稿から**24時間後**(公開終了後の最終インサイト)にストーリーログへ反映
- **投稿・リール**:投稿から**5日後**(数値が安定してから)に投稿ログ/リールログへ反映
- **日次ログ**:毎日、プロフィール全体のインサイト(概要+オーディエンス)を該当日の行に反映
- **週次ログ**:週の区切り(日曜日想定)で、その週の各ログを集計して1行追加
