# イクマ 運用グループ タスクボード

対象メンバー: 運用課長(レビュー)・公式LINE担当・定期配信担当・X担当・分析担当・リサーチ担当・流行り担当・SNSマーケティング担当・ローンチ担当・管理ツール開発担当

日次運用・配信・分析・ローンチ系の進行中タスクをここで管理する。日次チェックリスト自体は `reports/daily-ops-checklist.md`、判定基準は `reports/ops-policy.md` を参照(このファイルはそれらの「今の進捗」版)。

## 使い方

- 自分のタスクの状態・次のアクションを、作業したら自分で編集してpushする
- 状態は「未着手 / 進行中 / レビュー待ち(運用課長) / 保留 / 完了」を使う
- 2日連続で指標が平時の半分以下などの異常があれば、このファイルの「要注意」欄にも書いておく(週次PDCAでも見るが、気づいたらすぐ書いてOK)
