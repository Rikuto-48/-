# 毎日・毎週追うべき指標チェックリスト(イクマ様向け)

作成日: 2026-09-28

動線(投稿 → 保存/フォロー → プロフィール訪問 → DM相談)のどこが機能しているかを追えるように、
「毎日サッと見る指標」と「週次でじっくり見る指標」を分けています。

## 毎日チェックする指標

| 指標 | なぜ重要か | どこで見るか |
|---|---|---|
| フォロワー数(前日比) | 全体の勢いを一言で把握できる、一番分かりやすい健康診断 | プロフィール画面上部、または インサイト→概要 |
| リーチ(直近投稿・24時間以内) | 「投稿→保存/フォロー」の入口。そもそも見られていないと何も始まらない | 各投稿を開く→インサイトを見る、または インサイト→リーチ |
| プロフィールへのアクセス数 | 「保存/フォロー→プロフィール訪問」が機能しているかの直接指標。動線の中間チェックポイント | インサイト→概要→プロフィールのアクティビティ |
| リール視聴維持率(直近投稿) | 最初の数秒で離脱していないか=フックが効いているかの指標。保存/フォローの前提条件 | 各リールを開く→インサイト→「視聴時間」の項目 |
| その日に来たDM数(手入力) | 「プロフィール訪問→DM相談」の最終成果。ここが投稿担当としての一番のゴール指標 | DM受信箱を見て自分でメモ(自動集計不可) |

## 週次でチェックする指標

| 指標 | なぜ重要か | どこで見るか |
|---|---|---|
| 保存数・保存率(投稿ごと) | 「すぐ使える具体性」が刺さったかどうかの指標。ピラーごとの比較にも使える | 各投稿のインサイト→「保存」 |
| シェア数 | 人に勧めたくなる内容だったかの指標。DM相談に近い温度感の行動 | 各投稿のインサイト→「シェア」 |
| フォロー転換率(リーチ数に対するフォロー増加の割合) | 「単発で満足」で終わらず継続価値を感じてもらえたかの指標 | インサイト→オーディエンス(週の増減)とリーチを突き合わせて概算 |
| ピラー別の平均リーチ・保存率 | どのコンテンツピラー(HowTo/食事/あるある/マインドセット/Q&A/実績/都市伝説)が伸びているかの比較 | /admin/analytics ダッシュボード |
| DM→LINE転換率 | 最終ゴールに近いDM相談が、実際の個別サポートにつながっているかの指標 | DM・LINE登録数を手動で突き合わせ |

## 使い方の目安
- 毎日:5項目をサッと数字だけメモ(1〜2分)。急な落ち込みや伸びに早く気づくため
- 週次:5項目を振り返り、「どのピラーが良かったか」「動線のどこで詰まっているか」を判断し、翌週の投稿方針に反映

## 前提の注記
実績データがまだ少ないため、上記の指標選定・分け方は仮説ベースです。数週間分のデータが溜まったら、実際に「動線の詰まりを説明できている指標」かどうかを見直します。
