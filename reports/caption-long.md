# キャプション(長尺)戦略レポート

## ①理解度確認

- **コンセプト**:「服を脱いでも誇れる自分へ」— 見た目の取り繕いではなく、脱いだ後の身体に自信を持てる状態がゴール
- **ターゲット/ペルソナ**:20代前半・高卒社会人。すでにジムに通っているが脂肪が落ちず結果が出ていない層。「頑張っているのに成果が出ない」もどかしさが核心
- **トーン**:カジュアル・友達感覚。上から目線の指導口調ではなく、隣で一緒に考える距離感
- **CTA優先順位**:①プロフィールへの誘導 → ②保存/フォロー → ③DMシェア → ④LINE誘導(軽く触れる程度)

## ②戦略:長尺キャプションの型

### 基本方針

長尺は情報量が多い分、キャプションの役割は「動画の再視聴・保存を後押しする補足」+「次の行動への橋渡し」。台本の要点を繰り返すだけでなく、見た人が自分ごと化できる一言を冒頭に置くことが鍵。

### 4パーツ構成

1. **共感フック**(1〜2行、「あるある→実は原因はコレ」の流れ)
2. **要点まとめ**(箇条書き3〜4個、動画と重複させず「見返す時に使える情報」に絞る)
3. **補足ひとこと**(尺の都合でカットした「なぜそうなるか」を書き足し、キャプション単体の価値を作る)
4. **CTA**(1投稿1つに絞る、優先順位固定・文言はローテーション)

### 共感フックの具体例パターン

- 「ジム週4行ってるのに体変わらない…ってなってない?」
- 「頑張ってるのに数字が動かない時、大体原因はコレ」
- 台本のテーマに応じて「あるある」→「実はその頑張り方だと変わらない理由がある」という流れに固定する

### 要点まとめの書き方ルール

- 動画内で話した内容をそのまま書かない(重複は保存動機を下げる)
- 「見返す時に一番使えるポイント」だけ抜き出す(例:数字・NG行動・優先順位)
- 箇条書きの先頭は動詞か結論から始める(読み飛ばしても要点が拾える形)

### 補足ひとことの狙い

動画では尺の都合でカットした「なぜそうなるか」の一言を添えることで、キャプション単体にも価値を持たせる。これが「保存する理由」を作る(動画+キャプションで初めて完結する設計)。

### CTA文言ストック

| 優先度 | 例文 |
|---|---|
| ①プロフ誘導 | 「他のパターンもプロフィールにまとめてるから気になったら見て」 |
| ②保存/フォロー | 「これ系の投稿これからも出すから、保存とフォローだけしといて損はない」 |
| ③DMシェア | 「自分に刺さったら、たぶん友達にも刺さる。よかったら送ってあげて」 |
| ④LINE(軽く) | 「個別で相談したい人はLINEもあるよ」(文末に一言のみ) |

### 運用ルール

- 動画要約とキャプション独自情報は必ず分離(重複ゼロを目指す)
- 反応の良かったフック/CTA文言は都度ストックし、次のキャプションのドラフト時に再利用してパターン化する
- CTAは詰め込まず1投稿1択で優先順位を守る
- ペルソナの言葉遣い(高卒社会人・20代前半が実際に使う表現)に寄せ、説明口調にならないよう注意

## ③新運用方針:トライアルリール対応(2026-09-28共有)

Instagramの「トライアルリール」機能を使い、1本につき冒頭フック違いの3パターンを投稿。24時間後に一番伸びたものをフォロワー含む全体にシェアする運用(短尺・長尺どちらも対象、頻度は多くて2日に1回程度)。

**キャプション担当としての対応**
- 冒頭の共感フックを3パターン用意する
- 締めのCTA文言も、優先順位(①プロフ誘導→②保存/フォロー→③DMシェア→④LINE)は固定したまま、言い回しだけ3パターンに分けてバリエーションを持たせる
- 「要点まとめ」「補足ひとこと」部分は共通のまま、変えるのは冒頭と締めに絞る(検証の主眼をフックとCTA文言に置くため)

### Plan(前回までの計画)

- CTA優先順位:①プロフ誘導→②保存/フォロー→③DMシェア→④LINE

### Do(実行状況)

- 89日間で長尺動画の投稿はわずか3本(7/16・9/24・9/28)。短尺に比べて投稿頻度が著しく少ない

### Check(データで見えたこと)

1. **アカウント全体の推移**:7月(フォロワー純増 日平均+13.3人)→8月(閲覧数-47%、+5.5人)→9月(閲覧数は回復したが純増は日平均+3.9人で3ヶ月で最低)。直近2週間(週12・週13)は閲覧数が期間中最大まで回復(週13:リール閲覧平均1,321)したにもかかわらず、フォロワーはネットマイナス(週12:-2人、週13:-3人)。**「見られているのに増えない」状態が直近の最大の課題**
2. **フォロワー増加との相関係数**:プロフィールアクセス数 0.70(強)、プロフィールリンクタップ数 0.54(中)に対し、閲覧数 0.22・リール閲覧数 0.18・インタラクション数 0.18(弱〜ほぼ無関係)。**「見てもらう」より「プロフィールに来てもらう」ことの方がフォロワー増加に直結している**ことがデータで裏付けられた
3. **長尺動画の強み(過去ログ全体93本で比較)**:動画尺60秒以上(n=7)は平均閲覧数6,757と短尺15秒未満(n=64・平均107,162)の1/16程度しかないが、プロフィールアクセス率は1.82%で短尺の0.53%の**約3.4倍**、いいね率も1.34%で短尺の0.41%の**約3倍**。長尺はバズらないが「見た人を動かす」力が強い
4. **タイトル/フックの傾向**:プロフィールアクセス率が高い長尺動画は「胸トレが頑張れなかった日」「粘りに粘った日」「広島の若造が〜」など**個人の体験談・弱さの開示型**が上位に集中。逆に「クッパの甲羅」のような内輪ネタ的メタファーや、抽象的な仕組み論は下位に沈む傾向
5. **プロフィールリンクタップ数**:89日間合計224件(平均2.5件/日)。フォロワー増加との相関は0.54と中程度に強いにもかかわらず、絶対数が少なく伸ばす余地が大きい
6. **DM相談転換(KPI③)**:日次ログにDM数の列はあるが89日間すべて空欄で、**そもそも計測されていない**。現状の戦略が機能しているか検証不能な状態

### Act(次サイクルでの対応)

1. **長尺の投稿頻度を上げる**:3本/89日では量としての改善サイクルが回らない。プロフィール転換率の強みを活かすため、長尺の投稿頻度アップを陸斗さん/ピギーに提案する
2. **共感フックを「個人体験談・弱さの開示」型にシフト**:データで裏付けられた高pa_rateパターンを次回以降のキャプション冒頭フックのデフォルトにする(「〜日」「頑張れなかった」「等身大の体験」軸)
3. **CTAは「プロフィール誘導」優先を継続しつつ、リンクタップを増やす文言を強化**:現状2.5件/日は少なすぎる。「プロフィールに来てもらう」だけでなく「リンクまで押してもらう」一押しの文言を追加する
4. **直近2週間の「閲覧増・フォロワー減」を最重要課題として扱う**:見るだけで終わらせない導線になっているか、CTAの配置・頻度・優先順位の運用を見直す
5. **DM相談転換の計測体制がない点を課題として共有**:③のKPIを追えるようにする提案(ハイライトやリンクのクリックトラッキング等)をピギー/陸斗さんに上げる
6. **トライアルリール運用の3パターン検証に「個人体験談型フック」を軸として組み込む**:上記②の仮説をA/Bテストの中心軸にする
