# 長尺動画ネタ提案(ネタ・長尺担当)

## ①理解度確認

- **コンセプト**:「服を脱いでも誇れる自分へ」
  見た目の数値(体重・体脂肪率)そのものより、薄着になる瞬間(海・温泉・お風呂・恋愛シーン)に恥ずかしくない自分であることがゴール。自己肯定感の獲得が本質。
- **ターゲット・ペルソナ**:20代前半・高卒社会人。ジムには通っているが脂肪が落ちない人。
  継続する意志はあるが自己流/知識不足で結果が出ていない。時間・お金に余裕がない社会人生活。SNSは日常的に見ている(通勤・休憩中など隙間時間)。「頑張ってるのに報われない」ことへの焦り・劣等感を抱えている層。
- **トーン**:カジュアル・友達感覚。
  上から目線の指導者ではなく、「同じ目線に立つ、ちょっと詳しい友達/先輩」。専門用語は噛み砕く、堅苦しくしない、説教くさくしない。

## ②戦略立案

長尺動画の役割は短尺と異なり、「見た人を深く信頼させる」こと。10分見る人は既に興味を持った層なので、ここで信頼構築とDM転換を狙うのが本丸。

- **フォロワー増加**:短尺(リール)で「気になる」フックを作り、長尺で回収する導線を設計する。シリーズ化して世界観に引き込み、続きが気になる状態を作る(密着ドキュメントなど)。
- **保存/シェア増加**:「保存版」「完全網羅」型のコンテンツは保存されやすい。感情移入できるドキュメント形式は共感シェアされやすい。
- **DM相談への転換**:ペルソナと完全一致する人物(密着対象・Q&A回答者)を通じて「自分ごと化」させる。締めに自然な相談導線を置く(押し売り感を出さない)。

## 長尺ネタ案(全7本)

### 1. 密着ドキュメント「3か月後、脱げる自分になる」

| 項目 | 内容 |
|---|---|
| 狙う結果 | フォロワー増加(継続視聴によるファン化)/ DM転換(自分ごと化) |
| 出演者選定基準 | ターゲットと属性完全一致(20代前半・社会人・ジム歴あり・停滞中)。顔出し可否と発信への協力度を事前確認 |
| 構成の核 | 第1話「なぜ変わらないのか」を本人の言葉で言語化させる→視聴者の"分かる"を最大化 |
| 更新設計 | 3話以上のシリーズ化(初回カウンセリング/中間/成果)。短尺で各話のダイジェストを出し長尺へ誘導 |
| 保存/シェア要素 | 変化を数値でなく生活の場面(飲み会の断り方、コンビニでの選び方)で見せ、共感保存を狙う |
| DM導線 | 最終話ラストで「この人も同じところからのスタートだった」を明言→相談ハードル低下 |
| リスク/留意点 | 出演者のプライバシー配慮、途中で結果が出ない場合の編集方針を事前に決めておく |

### 2. 「ジムに1年通って体脂肪が減らない人の共通点、全部言います」

| 項目 | 内容 |
|---|---|
| 狙う結果 | 保存/シェア増加(教育的価値の高い網羅コンテンツ) |
| タイトル設計 | 数字を明示(例:「痩せない理由、7つ全部」)→保存率が上がる鉄板パターン |
| 構成の核 | 短尺の都市伝説シリーズで貼った伏線をここで回収→短尺視聴者を長尺に引き込む導線 |
| トーン担保 | 専門用語を出さず、給料や日常生活の例えに置き換える(高卒社会人ペルソナへの配慮) |
| 保存/シェア要素 | 「保存して見返せる」ことを動画内で明言し保存を促す一言を入れる |
| DM導線 | 「自分に当てはまる項目が多い人ほど個別相談が有効」という一言で自然にDM誘導 |

### 3. イクマ理論ロング解説「なぜ"筋トレだけ"では脂肪は落ちないのか」

- 権威性構築回。理論を友達感覚で噛み砕きながら話す(ホワイトボード/フリップ使用も検討)
- 高卒社会人=専門用語アレルギーがある前提で、たとえ話を多用(給料の使い方に例えるなど)

### 4. DM質問一斉回答「一番多い相談、全部答えます」

- 実際のDM(匿名化)を画面に出して読み上げ形式にすると信頼性・親近感が跳ねる
- 「こんな相談してもいいんだ」という心理的ハードルを下げる効果があり、次のDM流入を誘発する狙い撃ちコンテンツ

### 5. 都市伝説・深掘り検証シリーズ「筋トレ後に糖質を摂ると太るは本当か」

- 短尺で反応が良かった都市伝説ネタを選び、実際に検証(食べる/測る/専門家の意見を挟む)
- エンタメ性のある実験形式にすることで、教育系動画特有の"説教くささ"を回避しトーンを守れる

### 6. 対談「なんでジムに行っても変わらないの?」現役社会人3人に本音インタビュー

- ゲストはペルソナ本人たち(顔出しNGなら音声/モザイクでも可)
- 台本担当が拾いやすいよう、"あるある"発言を引き出す質問設計にするとよい

### 7. トレンド接続枠(仮・要リサーチ差し替え)

- 最近SNSで話題の健康トピック(オートファジー、腸活、プロテイン論争など)を「イクマが真偽判定する」形式
- 鮮度が命なので、リサーチ担当の最新トレンドが上がり次第、この枠だけ差し替え前提で確保

## 優先度メモ

1(密着)と2(完全網羅解説)は目的(フォロワー増・保存・DM転換)を同時に狙える2本柱として先に着手。3〜7はこの2本の反応を見ながら順次展開する。

- ⑦のトレンド枠はリサーチ担当の最新情報が来次第、内容差し替えが必要
