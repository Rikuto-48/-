# Instagramハイライト「継続」本番構成案

Issue #40 対応。ピギーのたたき台(5スライド構成)をベースに、画面テキスト・撮影指示・装飾まで本番用に仕上げたもの。

## 設計方針

- 陸斗さんの一人称の語り(「僕はこう思ってるんです◯◯」)を軸にする。説教調にならないよう、各スライドの締めは「〜のために、僕がいます」で統一し、"管理してくれる存在"としての距離感を出す
- 画面テキストは1行あたり全角13〜15文字を目安に改行(スマホ縦画面で詰まって見えないように)。改行位置は意味の区切りで入れている
- トーン: カジュアル・友達感覚。「〜してください」より「〜した方がいい」「〜でOK」寄りの言い回しに調整
- 全5スライド構成(たたき台どおり)。カバー表紙を含めて数える

---

## スライド1(表紙・フック)

**画面テキスト**
```
「行動しよう」は
もう死ぬほど
聞いたと思う

じゃあ
どうやったら
続くのか

僕はこう
思ってます
```

**ビジュアル/撮影指示**
- 陸斗さんが正面を見て話しかけるカット(ジムではなく私服・落ち着いた場所推奨。説教っぽく見えないよう、軽く笑っている表情から入る)
- 背景はシンプル(情報量を増やさない)。テキストは下半分〜中央に配置し、顔が隠れない位置に

**スタンプ・装飾**
- 「継続」ハイライトのカバー画像と統一感を出すフォント・色を使用(他ハイライトと揃える)
- スタンプは入れない(次のスライドへの誘導は自然なタップで十分)

---

## スライド2(チートデイ)

**画面テキスト**
```
忙しい人ほど
チートデイを
入れてOK

大会に出る
わけじゃないなら
自由な時間を
使った方がいい

自己肯定感が
上がる日があると
結局続く

このバランスを
計算するために
僕がいます
```

**ビジュアル/撮影指示**
- 「忙しい人ほど」のくだりは、陸斗さんが少し疲れた風の演技や、スマホを見ながら話す等、"忙しい日常"を感じさせるカットでも良い
- 締めの「僕がいます」のところだけ、カメラ目線に切り替える(1カット内でもOK、2カットに分けてもOK)

**スタンプ・装飾**
- 「チートデイ」の文字部分だけ色を変えるか下線で強調(視線誘導)

---

## スライド3(ペース配分)

**画面テキスト**
```
全力疾走で
やらないで

糖分を
取らないと
筋力はそもそも
出ません

最初から
全開でやると
必ず途中で
切れます

ペース配分を
一緒に決めるために
僕がいます
```

**ビジュアル/撮影指示**
- 「全力疾走」のイメージとして、トレーニング中にオーバーワークしている自分、または他人の失敗例の軽い再現(コミカルに)もアリ
- 専門的な内容(糖分と筋力の関係)なので、ここだけテロップ+静止画(図解無しでOK、あくまで一言解説)にして情報量を増やさない

**スタンプ・装飾**
- 「ペース配分」部分を強調

---

## スライド4(主体性)

**画面テキスト**
```
「言われてる
から続ける」
はダメです

指示待ち人間じゃ
続きません

自分自身で
走らないと
意味がない

僕に
ぶら下がらないで
ほしい

全部において
主体性が
一番大事です
```

**ビジュアル/撮影指示**
- このスライドが一番"本音トーク"になる部分。あえてテンションを落として、少し真面目な顔で話すカットにすると説得力が出る
- 1スライド内の文字量が多いため、テキストを2回のタップ分(2枚)に分割しても良い(下記「運用上の補足」参照)

**スタンプ・装飾**
- 装飾は最小限に(本音トーンを邪魔しない)

---

## スライド5(締め)

**画面テキスト**
```
継続は
この3つで
決まります

ここまで見た人は
電話相談で
同じこと
聞かなくてOK
```

**ビジュアル/撮影指示**
- 軽く笑って終わる(説教で終わらせない)
- 最後にプロフィール誘導のCTAスタンプを置く(①プロフィール誘導のCTA優先順位に合わせる)

**スタンプ・装飾**
- 「質問箱」スタンプ or 「もっと詳しく→プロフィール」の誘導テキストを1つだけ追加
- CTAは詰め込みすぎない(このハイライトの主目的は電話相談前の事前説明なので、プロフィール誘導は軽めでOK)

---

## 運用上の補足

- スライド4(主体性)は文字量がやや多いため、デザイン担当側で収まりが悪い場合は2枚に分割可(「言われてるから続ける〜意味がない」/「僕にぶら下がらないで〜主体性が一番大事」)。その場合は全体で6スライド構成になる
- 「筋肉とは」と異なり専門知識の正確性チェックは不要(陸斗さんの考え方そのものが内容のため)だが、言い回しのトーンは陸斗さん本人の口調に寄せられているか最終確認をお願いしたい
- 次工程(キャプション担当)への引き継ぎポイント: 4条件(①実話②ひと言で場面が浮かぶ③初心者が自分ごとにできる④上から教えず昔の自分と並ぶ目線)のうち、特に④「上から教えず」を各スライドの文言で意識(「〜してください」ではなく「〜した方がいい」寄りにしてある)
