# 短尺リール キャプション戦略ガイド

担当:動画チーム・キャプション(短尺)
対象:60秒尺リールの投稿キャプション

## ①ブランド理解

| 項目 | 内容 |
|---|---|
| コンセプト | 服を脱いでも誇れる自分へ |
| ターゲット | 20代前半・高卒社会人・ジムに通っているが脂肪が落ちない人 |
| トーン | カジュアル・友達感覚(タメ口寄り、絵文字最小限) |
| CTA優先順位 | ①プロフ誘導 → ②保存/フォロー → ③DMシェア → ④LINE誘導(信頼性の高い投稿のみ) |

## ②戦略:結果(保存/シェア増加・プロフ誘導・DM転換)を出すための方針

**原則:1投稿1メインCTA。** 短尺のテンポを守るため、CTAを詰め込まない。動画ネタの性質でその回の主目的を決めて逆算する。

### キャプションの型

```
1行目:共感/フック(動画内容の言い換え)
2行目:補足(なぜ・どうやって、一言で)
3行目:CTA(1つだけ)
```

全体60〜90文字目安。短尺は「読ませる」のではなく「見た直後に一押しする」役割。

### CTA別・使うタイミングとフレーズ例

**①プロフィール誘導(デフォルト・毎投稿の主軸)**
- 使うタイミング:解決策の"入り口"だけ見せるネタ
- 例:「やり方の続きはプロフから」「本気で変わりたい人はプロフ見て」
- コツ:命令形より「〜してる」「〜まとめてる」で押し付けがましさを回避

**②保存/フォロー**
- 使うタイミング:リスト・チェックリスト系、情報量のあるネタ
- 例:「これ系は保存必須」「明日ジム行く前に見返して」
- コツ:「いつ見返すか」を具体的に書くと保存率が上がる

**③DMシェア**
- 使うタイミング:共感煽り系・あるある系ネタ
- 例:「これ、ジム友達に送っといて」「"痩せない"って言ってる友達おったら送信」
- コツ:送る相手の悩みをペルソナと同じ状況で具体化する

**④LINE誘導(頻度を絞る)**
- 使うタイミング:実績・ビフォーアフター・専門性が伝わるネタのみ
- 例:「本気で相談したい人だけLINEで」
- コツ:毎回使わない。希少性を保って効かせる

### トーンのルール

- 語尾:「〜だよ」「〜してみて」「〜かも」(「〜しましょう」「〜です」は避ける)
- 絵文字:0〜1個
- 煽りは否定形でなく共感形(✗「まだそんなことしてるの?」→◯「これ知らずにやってる人多すぎる」)

### 今後の運用・検証方針

- 同一テーマで「プロフCTA版」「保存CTA版」を出し分け、保存数/プロフ遷移率を比較
- フレーズバンクごとの成果を記録し、勝ちパターンを型として固定化
- LINE誘導は投稿頻度に対して低頻度(実績系のみ)を維持し数値モニタリング
