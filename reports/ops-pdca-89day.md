# 89日間実績 PDCAレポート(運用課長)

作成日時: 2026-10-05
対象データ: `ikuma_89day_summary_3.xlsx`(対象期間 2026年7月3日〜9月29日、89日分)

## 0. 前提

- 本レポートは、陸斗さんから共有された実績データ(89日間サマリー)を初めて受け取り、運用課長として分析したもの。これまでの運用チームでの検討はリサーチ担当・投稿分析担当のセッション未稼働により仮説止まりだったが、今回は実データに基づく。
- 事前に数値目標を定めた文書は見当たらないため、ブランド方針のCTA優先順位(プロフィール誘導→保存/フォロー→DM→LINE)を暫定の評価軸として検証に用いた。

## 1. Plan(前提とした評価軸)

ブランド方針のCTA優先順位:①プロフィール誘導 → ②保存/フォロー → ③DMシェア → ④LINE誘導。この順位が実データ上も妥当かを含めて検証する。

## 2. Do(89日間の実績概要)

- 合計閲覧数:147,663回 / フォロワー純増:673人(平均+7.6人/日、ただし89日中18日(20%)は純減)
- 合計インタラクション数:1,551件 / 1日あたり平均プロフィールアクセス数:178.6件
- 月別推移:
  - 7月:閲覧2,194/日、フォロー+13.3/日(好調)
  - 8月:閲覧871/日(-60%)、フォロー+5.5/日、プロフィールアクセスも7月比-47%(急落)
  - 9月:閲覧1,967/日(リーチは回復)だが、フォロー+3.9/日(89日間で最弱)
- 週次では週7・週8(8月中旬〜下旬)が最低(閲覧200〜340/日)、直近の週13(9/25〜)で急回復(閲覧4,368/日)
- 曜日別では月・日が強く、金曜が全指標で最弱

## 3. Check(実データで見えた3つの重要な事実)

### 3-1. 「保存」はフォロワー増加にほぼ無関係。鍵は「プロフィールアクセス」
公式の相関係数シートでは、フォロワー純増との相関係数は プロフィールアクセス数=0.70(強い)、プロフィールリンクタップ数=0.54(中程度)に対し、閲覧数=0.22(弱い)、リール閲覧・ストーリーズ閲覧・インタラクション数=0.17〜0.18(ほぼ無関係)。

リール単体ログ(93本、期間外の過去データも含む)でも、保存率とフォロー数の相関は-0.03、いいね率も-0.14とほぼ無関係だった一方、プロフィールアクセス数との相関は0.97、閲覧数との相関は0.99と非常に強い。

→ ブランド方針のCTA優先順位で2番目に置かれている「保存」は、現状データ上はフォロワー増加への影響が薄い。1番目の「プロフィール誘導」をどう増やすかが実質的な最重要指標になっている。

### 3-2. 導線のボトルネックの一部は特定できたが、肝心な部分は未計測
- プロフィール訪問→プロフィールリンク(自己紹介)タップ率は平均1.2%(期間内平均)しかなく、ここが導線の大きな目詰まり。
- 一方「DM数」は89日分すべて未記録(空欄)。ブランドCTAの核心である「DM→LINE」のステップがそもそも測れていない。

### 3-3. リール単体ログの記録漏れとフックの弱さ
リールログシートには93本の記録があるが、対象の89日間(7/3〜9/29)に該当するのはわずか3本。月別集計の「リール閲覧(合計)」(例:7月15,736件)と比べると、期間中に投稿された大半のリールが個別ログに記録されていない。

記録済みリール(93本、過去データ含む)のスキップ率は平均54%と高く、フォロー数との相関は-0.36。冒頭での離脱が半数を超えており、フック(冒頭3秒)の弱さが構造的な課題として浮かぶ。

## 4. Act(次の一手)

1. **計測の穴を埋める(最優先)**:DM数を記録する運用を確立する(LINE担当・投稿分析担当と連携)。投稿されたリールを毎日、最低でも週次で個別ログに反映する運用に改める。これがないと③④の検証自体が進まない。
2. **プロフィール誘導の強化を最優先CTAとして再設計**:「保存して」訴求より「プロフィールを見て」の訴求・動線設計を優先する方向で、投稿分析担当と見直す。
3. **冒頭3秒のフック改善を制作側の最優先課題として共有**:スキップ率54%は明確な課題。先日共有された(本来動画チーム向けだった)トライアルリール運用(冒頭フック違いのA/Bテスト)の論点と直結するため、動画課長チームとの連携ポイントとして改めて共有する価値がある。
4. **8月急落/9月のリーチ回復とフォロワー転換率低下の「ねじれ」の原因調査**をリサーチ担当に依頼する(投稿休止・アルゴリズム変化・コンテンツ内容変化のいずれが原因か)。
5. **CTA優先順位の見直し提案**:実データが「保存」ステップの効果の薄さを示しているため、優先順位・施策配分をプロフィール誘導/リンクタップ中心に見直すことを提案したい。これは方針レベルの変更のため運用課長単独では決めず、陸斗さん/ピギーの確認を取る。
