# Instagramハイライト「筋肉とは」本番構成案

Issue #40 対応。ピギーのたたき台(4スライド構成)をベースに、画面テキスト・撮影指示・装飾まで本番用に仕上げたもの。

## 設計方針

- 教育系コンテンツなので「継続」より図解・比較を多めに使い、分かりやすさを優先する
- トーン: 教えすぎない。「知ってると得」くらいの距離感(ブランドの4条件④「上から教えず昔の自分と並ぶ目線」を意識)
- 画面テキストは1行あたり全角13〜15文字を目安に改行
- **要確認事項**: 「瞬発力タイプ/持久力タイプ」「筋肉内のエネルギーを溜める袋」等の説明は、たたき台の表現をそのまま使っている。Issue #40の注記どおり、数字・言い回しの正確性は陸斗さんの実際の知識に基づいて最終確認・修正をお願いしたい(このスライド構成では文字数・流れの設計までを本番用に仕上げ、専門知識の正確性チェックは次工程ではなく陸斗さん自身に委ねる)

---

## スライド1(表紙・フック)

**画面テキスト**
```
「筋肉って
何?」って
聞かれたら

答えられますか?
```

**ビジュアル/撮影指示**
- 陸斗さんが腕や肩を軽く指差す、または筋肉のイラスト風エフェクトを添えるカット
- クイズっぽく見せる(次のスライドへの期待感を作る)

**スタンプ・装飾**
- 装飾は最小限。クイズ感を出したい場合は「？」の絵文字スタンプ程度

## スライド2(構造の基本)

**画面テキスト**
```
筋肉は
細い線維
(筋繊維)の束

瞬発力タイプ
(太くなりやすい)

持久力タイプ
(太くなりにくい)

どっちを多く
鍛えるかで
見た目が変わる
```

**ビジュアル/撮影指示**
- 「線維の束」のイメージ図解(簡易イラスト、ロープやゴムのような束のイメージでOK)をテキストと一緒に配置
- 陸斗さんの実写カットよりも、図解+テロップ中心のスライドにする(情報量が多いため)

**スタンプ・装飾**
- 「瞬発力タイプ」「持久力タイプ」をそれぞれ違う色のハイライトで区別(視覚的に対比が伝わるように)

## スライド3(なぜ細い人とゴツい人がいるのか)

**画面テキスト**
```
細い人と
ゴツい人がいる
理由は3つ

①骨への
筋肉の付き方は
人それぞれ

②体脂肪が多いと
輪郭が隠れる

③筋肉内の
エネルギーを
溜める「袋」の
大きさの違い
```

**ビジュアル/撮影指示**
- 3つの理由は番号を振って順番に見せる(1スライドに詰め込みすぎる場合は3枚に分割も検討。下記「運用上の補足」参照)
- ③の「袋」は比喩表現なので、誤解を招かないよう、デザイン担当への引き継ぎ時に「あくまで分かりやすい言い換え」である旨を明記しておく

**スタンプ・装飾**
- ①②③の番号部分を丸囲みなどで強調

## スライド4(締め)

**画面テキスト**
```
「細く見える」
=筋肉がついてない
わけじゃない

「ゴツく見える」
=強いわけでもない

見た目だけで
焦らなくて
大丈夫
```

**ビジュアル/撮影指示**
- トーンを落として安心させる話し方。表情は柔らかく
- 最後にプロフィール誘導のCTAスタンプ(①プロフィール誘導のCTA優先順位に合わせる。教育系ハイライトなので、ここでは「もっと知りたい人はプロフィールへ」程度の軽い誘導)

**スタンプ・装飾**
- CTA誘導テキストまたはスタンプを1つ

---

## 運用上の補足

- スライド3は情報量が多いため、デザイン担当側で収まりが悪い場合は①②③を1枚ずつ、計3枚に分割可(その場合、全体で6スライド構成になる)
- 専門知識(筋繊維タイプ・脂肪と輪郭の関係等)の正確性は、Issue #40の注記どおり陸斗さんの実際の知識・経験に基づいて必ず最終確認してもらうこと。本構成案は文字数・流れ・見せ方の設計まで
- 次工程(キャプション担当)への引き継ぎポイント: 「筋肉とは」は教える系コンテンツのため、4条件のうち③「初心者が自分ごとにできる」を特に意識し、専門用語(筋繊維・タイプ等)が初心者にとって難しくなりすぎないよう言い回しを調整してほしい
