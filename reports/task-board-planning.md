# イクマ 企画グループ タスクボード

対象メンバー: 企画課長(レビュー)・ネタ担当・台本・構成担当・キャプション担当・ストーリー担当・リール担当・動画編集担当・note担当・運用チーム リール・ストーリー

コンテンツ1本ができるまでの工程(ネタ→台本・構成→キャプション→動画編集→投稿)をここで追いかける。工程ごとの担当がバトンタッチしていく形。

## 使い方

- 自分の工程が終わったら、「状態」を更新して「次の担当」に回す(ファイルを直接編集してpush)
- 次の担当は、自分宛てのバトンが来ているかこのファイルで確認できる(気づいたらでOK。急ぎの時はピギーからも一声かける)
- 状態は「未着手 / 作業中 / 完了→次工程へ / レビュー待ち(企画課長) / 差し戻し / 投稿済み」を使う
- 行が多くなってきたら、投稿済みの古い行は下の「完了済み」セクションに移すか削除してOK
