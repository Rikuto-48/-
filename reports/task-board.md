# イクマ 全体タスクボード

全チーム共通。大きな方針決定・複数チームが絡む進行中の取り組みをここで管理する。
細かい制作の工程(リール1本ごとのネタ→台本→キャプション→動画編集など)は `task-board-planning.md`(企画グループ)、日次運用・配信・分析系は `task-board-ops.md`(運用グループ)を見ること。

## 使い方

- 自分が関わる項目の「状態」「次のアクション」「最終更新」を、作業したら自分で編集してpushする(このファイルを直接書き換えてOK、PRは不要)
- 新しい全体方針・複数チーム関連の取り組みができたら、ピギーか陸斗さんが行を追加する
- 状態は「未着手 / 進行中 / レビュー待ち / 保留 / 完了」のいずれかを使う
- 「最終更新」は `YYYY-MM-DD 担当名` の形式で書く
