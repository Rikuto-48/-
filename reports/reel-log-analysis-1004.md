# リールログ分析レポート(尺・視聴維持率)

作成日: 2026-10-04(2026-10-05 更新)
作成: 投稿・分析担当
データソース: 陸斗さん提供「ikuma_89day_summary_3.xlsx」の `リールログ` シート(個別リール93本、2025/6/20〜2026/9/28)

## 0. このレポートの位置づけ

同ファイルの「概要サマリー/月別集計/曜日別集計/週次推移/相関係数」は、`reports/account-analysis-0929` とほぼ同一の数値・結論だったため本レポートでは割愛する。

新しい価値は `リールログ` シートにあり、これは `reports/account-analysis-0929`・`reports/reel-analysis-0929`・`reports/story-analysis-0929` の3レポートが揃って「視聴維持率が全く記録されていない」と指摘していたデータそのものにあたる。「動画尺」「平均再生時間」から視聴維持率(平均再生時間÷動画尺)を算出できたため、本レポートではこれを中心に分析した。

なお対象93本のうち、7/3〜9/29の89日間分析ウィンドウに収まるのは3本のみで、大半(90本)はそれ以前(2025/6〜2026/6)の個別記録だった。そのため本レポートは「直近89日間」ではなく「これまでの個別リール記録全体」を対象とした分析である点に注意。

本レポートは `reports/reel-duration-retention-analysis-1004` ブランチ(PR #20)で、閲覧数の突出した7本を外れ値として除外した初版を提出したが、陸斗さんに実データと確認いただいたため、全93本を対象に再集計した(リール分析担当の `reports/reel-log-analysis-1004` の分析と対象データ・前提が一致している)。

## 2. ①何が弱いか

1. **動画が長いほど視聴維持率・リーチとも悪化する(相関: 尺×視聴維持率 -0.73、尺×閲覧数 -0.13)**。30秒超は平均視聴維持率19%・中央値閲覧数3,214件。10秒以下は平均視聴維持率136%・中央値閲覧数8,551件。バズった7本を含めても、尺が短いほうが一貫して強い(中央値ベースなので外れ値の影響を受けにくい)。
2. **スキップ率が全体的に高い(平均55%、中央値55%)**。尺の長さとほぼ無相関(相関0.04)であり、「長いから飛ばされる」のではなく、**冒頭フック自体が弱く、半数以上が早々に離脱している**ことを示す。
3. **スキップ率はフォロー獲得数と逆相関(-0.36)**。スキップされるほどフォローされない関係が裏付けられた。
4. **直近89日分のリール(3本)は過去実績より明らかに弱い**。過去全体平均は閲覧9,090件超(中央値5,303件)に対し、直近3本は2,130〜4,349件に留まる。サンプル数が少なく参考値だが、方向性としては弱含み。
5. **投稿頻度が時系列で大きく減少している**(リール分析担当の指摘と一致):2025年後半57本→2026年前半23本→2026年7〜9月はわずか3本。

## 3. ②どういう傾向があるか

- **短尺(10秒以下)が圧倒的に強い**:中央値閲覧数8,551件(11〜30秒は4,700件、30秒超は3,214件)、平均視聴維持率136%。
- **視聴維持率が高い投稿ほど閲覧数も伸びる(相関0.30)**。
- **閲覧数とフォロー獲得数は極めて強い相関(0.99)**。「リーチさえ出れば成果は自動的についてくる」構造になっており、リール分析担当の分析(r=0.987)と一致する。
- 突出した7本はいずれも2025年(1本のみ2026年2月)に集中しており、2026年に入ってからは同規模のヒットが出ていない。
- 平均尺は20秒、短尺(10秒以下)が93本中55本と過半数を占める、短尺中心の運用。

## 4. ③どうすれば継続して高い数値を残せるか

1. **投稿頻度を2025年後半の水準(月9本程度)まで戻すことを最優先とする**。閲覧数とフォロー獲得数の相関が0.99と極めて強いため、「リーチを出す本数」自体を増やすことが最も効果の大きい打ち手。これはリール分析担当の提案と一致する。
2. **尺を10秒前後に統一する方針を台本構成担当と共有する**。中央値ベースでも短尺の優位性は明確なため、「1テーマ=10秒以内で完結」をデフォルトルールとして提案する。
3. **スキップ率(平均55%)を下げる=冒頭フックの強化**。尺の長さでは説明できない離脱であるため、台本冒頭1〜2秒を重点的に見直す。
4. **過去の突出した7本の内容を横展開する**。「酒太り」「タバコ」など生活習慣×筋トレの対比ネタ、「6つの意識の違い」の再投稿実績(リール分析担当の分析で確認済み)など、ネタ担当と連携して実証済みの型を再現する。
5. **引き続きリールログへの記録を継続する**。直近89日分はサンプル数3本のみで傾向を断定できないため、継続的な記録によって確定させる。

## 5. 前提の注記

- 「動画尺」列はExcel上 `h:mm` 形式で保存されていたが、値そのものは「分:秒」として入力されたものと判断し、`時間×60+分` を秒数として読み替えて算出した(例:セル表示「0:17」→17秒)。実際のアカウント個別インサイト(本会話内で確認済みの「二頭で妊娠するためにやること」リール:動画尺17秒・平均再生時間7秒)と整合することを確認済み。
- 視聴維持率が100%を超える値(ループ再生込み)が一定数あり、これは「1回視聴での最後まで到達率」ではなく「平均再生時間が動画尺の何倍か」を示す指標である点に注意。
