# リールログ分析レポート(尺・視聴維持率)

作成日: 2026-10-04
作成: 投稿・分析担当
データソース: 陸斗さん提供「ikuma_89day_summary_3.xlsx」の `リールログ` シート(個別リール93本、2025/6/20〜2026/9/28)

## 0. このレポートの位置づけ

同ファイルの「概要サマリー/月別集計/曜日別集計/週次推移/相関係数」は、`reports/account-analysis-0929` とほぼ同一の数値・結論だったため本レポートでは割愛する。

新しい価値は `リールログ` シートにあり、これは `reports/account-analysis-0929`・`reports/reel-analysis-0929`・`reports/story-analysis-0929` の3レポートが揃って「視聴維持率が全く記録されていない」と指摘していたデータそのものにあたる。「動画尺」「平均再生時間」から視聴維持率(平均再生時間÷動画尺)を算出できたため、本レポートではこれを中心に分析した。

なお対象93本のうち、7/3〜9/29の89日間分析ウィンドウに収まるのは3本のみで、大半(90本)はそれ以前(2025/6〜2026/6)の個別記録だった。そのため本レポートは「直近89日間」ではなく「これまでの個別リール記録全体」を対象とした分析である点に注意。

他86本の中央値は4,394件であり、これらは100〜500倍以上の外れ値。実際の大ヒットである可能性もあるが、これまでの会話で確認してきた実績の規模感(数百〜数千件)とかけ離れているため、入力ミスの可能性も否定できない。**本分析ではこの7本を外れ値として除外し、残り86本を集計対象とした。** 実数値であれば別途確認し、ヒットの要因分析に活用したい。

## 2. ①何が弱いか

1. **動画が長いほど視聴維持率・リーチとも悪化する(相関: 尺×視聴維持率 -0.74、尺×閲覧数 -0.25)**。30秒超の尺は平均視聴維持率わずか19%(最後まで見られていない)。10秒以下は129%(ループ再生を含め繰り返し見られている)。長尺化が明確に不利に働いている。
2. **スキップ率が全体的に高い(平均55%、中央値55%)**。尺の長さとほぼ無相関(相関-0.03)であり、「長いから飛ばされる」のではなく、**冒頭フック自体が弱く、半数以上が早々に離脱している**ことを示す。
3. **スキップ率はフォロー獲得数と強く逆相関(-0.51)**。スキップされるほどフォローされない、という関係が数値で裏付けられた。視聴維持率とフォロー数の相関は弱い(+0.12)一方、スキップ率は強く効いている。
4. **直近89日分のリール(3本)は過去実績より明らかに弱い**。過去全体平均は閲覧9,090・視聴維持率89%に対し、直近3本は閲覧3,523・視聴維持率33%。サンプル数が少なく参考値だが、方向性としては悪化している。

## 3. ②どういう傾向があるか

- **短尺(10秒以下)が圧倒的に強い**:平均閲覧11,855件・視聴維持率129%。中尺(11〜30秒)は閲覧5,605件・視聴維持率50%、長尺(30秒超)は閲覧5,038件・視聴維持率19%まで落ちる。
- **視聴維持率が高い投稿ほど閲覧数も伸びる(相関0.46)**。アルゴリズムが視聴維持率を評価し配信量を増やしている可能性が高い。
- 全体の平均尺は20秒・中央値6秒で、アカウント全体として基本的に短尺運用が主体。

## 4. ③どうすれば継続して高い数値を残せるか

1. **尺を10秒前後に統一する方針を台本構成担当と共有する**。長尺化するほど視聴維持率・リーチとも悪化する関係が明確なため、「1テーマ=10秒以内で完結」をデフォルトルールとして提案する。
2. **スキップ率(平均55%)を下げる=冒頭フックの強化を最優先課題とする**。尺の長さでは説明できない離脱であるため、台本冒頭1〜2秒(結論先出し・衝撃的な一言など)を重点的に見直す。フォロー獲得とも直結する(スキップ率とフォロー数が逆相関-0.51)。
3. **過去の突出した閲覧数7本(実数値であれば)の内容を横展開する**。タイトル傾向(「酒太り」「タバコ」など生活習慣×筋トレの対比ネタ)をネタ担当と確認し、同系統の切り口を再現できないか検討する。
4. **引き続きリールログへの記録を継続する**。直近89日分はサンプル数3本のみで「悪化」と断定はできないため、継続的な記録によって傾向を確定させる。

## 5. 前提の注記

- 「動画尺」列はExcel上 `h:mm` 形式で保存されていたが、値そのものは「分:秒」として入力されたものと判断し、`時間×60+分` を秒数として読み替えて算出した(例:セル表示「0:17」→17秒)。実際のアカウント個別インサイト(本会話内で確認済みの「二頭で妊娠するためにやること」リール:動画尺17秒・平均再生時間7秒)と整合することを確認済み。
- 視聴維持率が100%を超える値(ループ再生込み)が一定数あり、これは「1回視聴での最後まで到達率」ではなく「平均再生時間が動画尺の何倍か」を示す指標である点に注意。
