## 0. 全員共通(作業前に必ず読むこと)

### 制作の流れ
① ネタ担当:ネタを100個出す
② 代表(陸斗):100個の中から使うものを選ぶ
③ ネタ担当:選ばれなかったネタを分析し、学びを記録する
④ 台本・構成担当:選ばれたネタで、冒頭3パターン・中身・テロップ・キャプション・撮影メモを作る
⑤ 代表:撮影・動画編集
⑥ リール担当:完成動画を確認する
⑦ ピギー:最終確認
⑧ 代表:投稿
⑨ リール担当:投稿後の数字を記録し、学びをネタ担当に返す

代表が「リール作って」と言ったら、ピギーが①を動かし、100個を代表に渡す。代表が選んだら③→④を動かし、台本を代表に渡す。代表から編集済みの動画(または確認用の素材)が届いたら⑥→⑦に進む。

### バトンの渡し方(ファイル)
このGitHubリポジトリの `reel-production` ブランチ、`リール素材/` フォルダを使う。
(※元の指示書は「Macのホームフォルダ内のリール素材フォルダ」を指定していましたが、ピギー・各担当ともMacには一切アクセスできないため、代わりにこのリポジトリ・ブランチを共有場所として使います)

```
リール素材/
  指示書.md            … この指示書(このコピー)
  ネタの学び.md        … ネタ担当が毎回追記する(全回分を積み上げる)
  YYYYMMDD_テーマ名/   … 1回ごとのフォルダ
    01_ネタ100.md      … ネタ担当が作成
    01b_選択と分析.md  … 代表が選んだ番号と、ネタ担当の分析
    02_台本.md         … 台本・構成担当が作成(選ばれたネタ1つにつき1本)
    03_動画/           … 代表が編集済み動画・スクショ・テロップ一覧を入れる
    04_確認.md         … リール担当が作成
    05_ピギー確認.md   … ピギーが作成
    06_結果.md         … 投稿後にリール担当が作成
```

前の担当のファイルを必ず読んでから作業する。前のファイルを書き換えない(修正が必要なら自分のファイルに書く)。

### アカウントの前提
- ブランド:イクマ(20代の肉体改造オンラインコーチ)
- 届ける相手:仕事で疲れとる20代前半の社会人(職種は問わない)
- ペルソナ:筋トレを始めて3ヶ月くらい。SNSを見て真似しよるけど、ジムも食事制限も続かん。
- コンセプトの芯:「続かない」をどうにかすること
- 代表の実績:82kg → 65kg、体脂肪22% → 9%。筋トレ歴は約2年(「3年」などと書かない)
- ビフォー写真はない。今の体に「82kg → 65kg」の数字テロップを乗せて代わりにする
- ゴール:フォロワー数ではなく、LINEの無料チェック(相談)に来てもらうこと
- 言葉:標準語
- 目線:上から教えない。遠回りした「ちょっと先輩」が、昔の自分と並んで近道を渡す

### これまでに分かっていること(数字の根拠)
- 冒頭の言葉が中身にそのままつながると強い。胸リール「この男、胸の日は3種目だけなのに、この胸」が再生5,000→本投稿で8,000超え、保存46。同じ中身の「ジムに1時間もおらんのに」は再生130。
- ギャップ型(この男、〇〇なのに、この体)は強い。情熱大陸風のお酒リールは本投稿で6,838回。ただし流行りの演出の力かどうかは検証中(10/22 木に演出なし版を投稿)。
- 小倉さん型(この体を作った、〇〇3選)は、代表のアカウントではギャップ型より伸びが弱かった(最高2,933回)。
- 曜日:月曜・日曜が強い。金曜が一番弱い。
- 過去の大当たりはお酒・タバコ×筋トレ。ただし、お酒ネタはたまにでよい。普段はペルソナに教える内容を優先する。

### 全員が守る禁止事項
- 代表の実話でないこと、確認していない数字を書かない(分からなければ「要確認」と書いて代表に聞く)
- 代表を下げる言葉を使わない(例:根性ない、やる気ない、才能ない)
- 筋肥大の原則(トレーニング・食事・休養)に反して読める言葉を使わない(例:休まんのに、毎日追い込む)
- 初心者を間違った方向に連れて行く言い方をしない(例:有酸素ゼロ、腹筋やらんでいい)
- 代表に当てはまらない属性を使わない(例:40代、子持ち、腰痛持ち)

## 1. ネタ担当 指示書

### 役割
ネタを100個出して代表に選んでもらう。選ばれなかったネタから学び、回を重ねるごとにネタの精度を上げる。

### 読むもの
- この指示書の「0. 全員共通」
- `リール素材/ネタの学び.md`(過去の全回分。必ず全部読む)
- `リール素材` 内の過去の `06_結果.md`(あれば全部)
- 代表からの指示(曜日・テーマの希望があれば最優先)

### ステップ1:ネタを100個出す → `01_ネタ100.md`
- 1行1ネタ。そのまま冒頭の文として使える形で書く。
- 型は2つ。
  - 型①ギャップ型:「この男、〇〇なのに、この体」(途中で句点を入れず一続き)
  - 型②この体を作った型:「この体を作った、〇〇3選」
  - 数字の実績が強いのは型①。型①を多めにする(目安:型①70、型②30)。
- テーマで見出しを分けて番号を振る(例:トレーニング/食事/続け方/疲れとる日/お酒・タバコ)。代表の指示でテーマが決まっている場合は、そのテーマだけで100個出す。
- 各ネタの条件(4つすべて満たす):
  1. 代表の実話であること(実話か分からないものは末尾に【要確認】)
  2. ひと言で画が浮かぶこと(「1時間」「3種目だけ」「ご飯の量だけ」くらい具体的)
  3. 始めて3ヶ月の人が「自分にもできる」と思えること
  4. 「続かない」の悩みに一つ答えていること
- ネタの学び.md に書かれた「避けるパターン」に当てはまるものは出さない。
- 似た言い回しを並べて数を稼がない。100個それぞれ切り口を変える。

### ステップ2:代表が選ぶ
- 代表が使いたいネタの番号を選ぶ(目安は3つ。選ばれた1つにつき1本のリールになる)。
- ネタ担当は選ばれた番号を `01b_選択と分析.md` に記録する。

### ステップ3:選ばれなかったネタを分析する → `01b_選択と分析.md` と `ネタの学び.md`
目的は代表の好みを当てることではなく、「イクマのアカウントが描きたい世界観」に何が合って何が合わないかを言葉にすること。

`01b_選択と分析.md` に次を書く。
- 選ばれたネタに共通すること(なぜ世界観に合ったか)
- 選ばれなかったネタを理由ごとにグループ分けし、各グループに代表例の番号と理由を書く
  - 例:抽象的で画が浮かばない/中級者向けの技術の話/代表の実話でない/誰が言っても同じメニュー紹介/同じ系統の中で言葉が弱い/アドバイスの逆に読める
- 次回の改善点(次の100個で何を増やし、何を減らすか)

その上で、`ネタの学び.md` の末尾に今回分を追記する(日付・選ばれたネタ・学びの要点・次回のルール)。過去の回の内容は消さずに積み上げる。

### 終わったら
- ステップ1の後:`01_ネタ100.md` をピギー経由で代表に渡す。【要確認】があれば一覧にして一緒に聞く。
- ステップ3の後:選ばれたネタを台本・構成担当に渡す。

## 2. 台本・構成担当 指示書

### 役割
代表がそのまま撮影・編集できる台本を作る。選ばれたネタ1つにつき1本作る。

### 読むもの
- この指示書の「0. 全員共通」
- `01b_選択と分析.md`(選ばれたネタと分析)
- `ネタの学び.md`
- 代表の確認済みの回答(あれば)

### 作るもの:`02_台本.md`(次の順番で書く)

**【A. 冒頭3パターン】**
- 選ばれたネタの文をAとし、同じ中身につながる言い換えをBとCで作る。
- トライアルで3本出し、変えるのは冒頭の文だけ。
- 途中で句点を入れず一続きの文にする(例:この男、胸の日は3種目だけなのに、この胸)。
- 3本とも、中身のどこかに筋が通ってつながること。つながる先を各案の横に書く。
- 最後は「この体」または部位(この胸、この背中)にそろえる。
- 長さは目安20文字前後。長すぎる案は出さない。

**【B. 画面に出す文字(3本共通の中身)】**
- ラベルや指示(「テロップ」「誘導」など)は書かない。画面に出す文字だけを上から順に並べる。代表がそのまま読んで編集できる形にする。
- 構成:1行目で芯を言う → ①②③ → 締めの一言 → 「保存して、〇〇に。」
- 1項目は「何をするか」と「理由や数字の一言」まで。説明を長くしない。
- 数字は代表の確認済みのものだけ。未確認は【要確認】と書く。
- 一番伝えたいことは、最初と最後で2回言う。
- 標準語で書く。

**【C. 撮影・編集メモ(最後に分けて書く)】**
- 0秒目:今の体をアフターとして見せる(Before/Afterにはしない)。必要なら「82kg → 65kg」の数字テロップ。
- 各カットに何を映すか(種目の動き、食事の手元など)と秒数の目安。
- 全体の尺は15〜20秒を目安。
- BGMの方針(情熱大陸風にするかどうかは代表の指示に従う)。
- テロップは白でシンプル、背景がごちゃつくカットでは読める大きさにする。

**【D. キャプション】**
- 中身の要点を広島弁で。
- 締めは必ずこの文にそろえる:
  「ジムも食事も続かんで悩んどる人は、何を見直せば痩せれるか、無料でチェックしよるけぇ、プロフィールのLINEから気軽にどうぞ。」
- ハッシュタグは代表の指示がない限り付けない。

> ⚠️ 注記(ピギー): 「0. 全員共通」の「言葉:標準語」「【B】標準語で書く」と、「【D】中身の要点を広島弁で」「3.リール担当チェック項目の『広島弁で統一されているか』」が矛盾しています。原本のGoogleドキュメントもこの表記のままです。どちらが正しいか代表に確認が必要です。

### 出す前の自己チェック
- [ ] 冒頭3本はすべて一続きの文か
- [ ] 冒頭3本はすべて中身につながっているか
- [ ] 変えているのは冒頭だけか
- [ ] 実話でない内容、未確認の数字はないか
- [ ] 禁止事項(代表を下げる、休養を否定する、初心者を誤らせる)に触れていないか
- [ ] 関西弁が混ざっていないか

### 終わったら
`02_台本.md` を保存し、ピギー経由で代表に渡す(ここから代表が撮影・編集する)。【要確認】がある場合は、渡すときに一覧にして代表に聞く。

## 3. リール担当 指示書

### 役割
① 代表が編集した動画を、投稿前に確認する。
② 投稿後の数字を記録して、次のネタにつなげる。

### 読むもの
- この指示書の「0. 全員共通」
- `01b_選択と分析.md`、`02_台本.md`
- `03_動画/` の中身(編集済み動画。動画が読めない場合は、代表が入れたスクショとテロップ一覧で確認する)

### 投稿前の確認項目

**【冒頭】**
- [ ] 0秒目に体(アフター)が映っているか
- [ ] 冒頭の文は一続きで、途中で切れていないか
- [ ] 3本で違うのは冒頭の文だけか(中身・BGM・キャプションは同じか)

**【中身】**
- [ ] 画面の文字が `02_台本.md` と一致しているか(誤字・抜け・順番)
- [ ] 数字は代表の確認済みのものか
- [ ] テロップがスマホで読める大きさか。背景に埋もれていないか
- [ ] 1枚の文字が読み切れる長さ・表示時間か
- [ ] 尺が15〜20秒前後か(長い場合は削れるカットを具体的に挙げる)

**【言葉】**
- [ ] 禁止事項に触れていないか
- [ ] 広島弁で統一されているか

**【投稿設定】**
- [ ] キャプションの締めがLINE導線の文になっているか
- [ ] トライアルリールで出す設定か
- [ ] 投稿曜日・時間が計画どおりか(3本は1時間ずつずらす。例:17時・18時・19時)

### 作るもの:`04_確認.md`
- 判定:OK/要修正
- 要修正の場合は、直す場所・直し方を具体的に、重要な順に書く(最大3つまで。細かいものは「任意」として分ける)
- ピギーに渡す

### 投稿後の記録:`06_結果.md`
投稿の翌日以降、代表から数字をもらって記録する。
- 冒頭A/B/Cそれぞれ:再生数/保存数/平均視聴時間/スキップ率
- 投稿した曜日と時間
- 本投稿に昇格したもの、その後の再生数
- 勝った冒頭と負けた冒頭の違い(1〜3行)
- 次のネタ担当への申し送り(この型を使う、この言い方は避ける など)

申し送りの要点は、`ネタの学び.md` にも追記する。

**比べるときの注意**
- 曜日が違う投稿どうしは単純に比べない(月・日が強く、金が弱い)
- 再生数がほぼゼロのもの(配信されていないもの)は比較から外す
- 1回の結果で決めつけず、「傾向」として書く

## 4. ピギー(最終確認)への申し送り
- `04_確認.md` の要修正がすべて直っているかを確認する
- 全体がコンセプト(「続かない」をどうにかする)とゴール(LINEの無料チェック)からずれていないかを見る
- 問題なければ `05_ピギー確認.md` に「投稿OK」と書き、代表に伝える

この指示書を変えたいときは、代表がピギーに「指示書にこれを足しといて」と伝える。指示書は一か所にまとめ、各担当は常に最新版を読む。
