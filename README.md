# 軌道整備計算シート

鉄道の保線業務（軌道整備）を支援するツール。線区・区間ごとの軌道狂い測定データを入力し、
整備基準値との比較判定・統計計算・整備計画の管理・帳票出力までを行う。

## 主な機能

- **測定データ入力**: 線名・キロ程で区間を登録し、距離ごとの通り狂い・高低狂い・水準狂い・軌間狂い・平面性狂いを入力
- **軌道狂い計算**: 整備基準値（注意値・整備値）との比較判定（良好・要注意・要整備）、区間ごとの平均・標準偏差・最大絶対値を算出
- **整備計画・記録管理**: 区間・狂い種別ごとに整備計画（予定日・担当者・整備方法・状況）を登録・追跡
- **帳票出力**: 区間ごとの計算シートを印刷用ページとして表示、測定データをCSVで出力
- **整備基準値設定**: 基準値セット（注意値・整備値）を複数作成・編集可能。初期値はサンプルのため、必ず自社の運用基準に置き換えること

## 技術構成

- フロントエンド: React + TypeScript + Vite
- ルーティング: react-router-dom
- データ保存: ブラウザのlocalStorage（バックエンド不要のクライアント完結型）

## セットアップ

```bash
npm install
npm run dev
```

## ディレクトリ構成

```
src/
  types.ts        軌道狂い・区間・整備計画などの型定義
  data/           整備基準値の初期サンプル値
  lib/            localStorage永続化、判定・統計計算、CSV出力、DBコンテキスト
  components/     共通レイアウト
  pages/          ダッシュボード・測定データ入力・計算結果・整備計画・整備基準値設定・帳票
```
